# ScholarOS

ScholarOS is an open-source, modular, multi-agent AI research platform that orchestrates local language models, domain-specific tools, and retrieval systems to assist researchers across multiple scientific and engineering disciplines.

## Status

🚧 Under active development.

## Vision

ScholarOS aims to become an extensible research operating system capable of:

- Literature review
- Retrieval-Augmented Generation (RAG)
- Computer Vision
- Code generation and execution
- Experiment management
- Multi-agent collaboration
- Scientific report generation
